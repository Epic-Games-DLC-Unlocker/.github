# A universal Epic Games Launcher DLC Unlocker Tool

**EGSUnlocker** is a all-in-one tool that automatically detects, unlocks, downloads and activates DLCs for supported games. It simplifies DLC management across multiple platforms with no manual file editing required.

## 🧩 Overview

CreamAPI streamlines the entire DLC activation process by scanning your system, detecting installed games, and generating the necessary DLC configuration files automatically. It is designed to be fast, efficient, and easy to use.

### Supported Platforms
- Epic Games Store  

---

## 🕹️ Usage Instructions

1. Launch **EGSUnlocker**  
2. Select the platforms and games you want to scan  
3. Wait for **SteamCMD** to initialize (Steam games only)  
4. Allow the program to gather game and DLC information  
   *(First scan may take longer)*  
5. Follow the on-screen instructions  
6. Click **OK** when the process is complete

---

## ⚙️ Features

### 🔍 Automatic Game Detection
- Scans your system for installed games from Epic Games
- Automatically finds required game and DLL directories

### 🧠 Smart DLC Data Parsing
- Parses DLC data using and Epic Games Store
- Caches retrieved information for faster future scans

### 📁 Handy Right-Click Utilities
- Open parsed app info in **Notepad++**
- Refresh Steam and Epic app data
- Open game folders and DLL locations in **File Explorer**
- Quickly access related platform pages

---

## 🚀 Getting Started

1. Download the latest release  
2. Extract the archive to any folder  
   *(Portable application – no extra dependencies required)*  
3. If the app fails to launch, install **.NET 7 Runtime**

> ⚠️ **Important**  
> EGSUnlocker does **not** download or provide DLC files.  
> It only generates and activates DLC configuration data.
